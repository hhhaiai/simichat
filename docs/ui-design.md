# 移动端优先界面规范与设计系统

> 对应模块：M11。状态：移动端主链路、字体缩放、附件卡片、图片缩略图、扩展 Markdown 渲染、音频转写状态展示、转写详情查看 / 复制、STT 配置入口、TTS 语音播报入口、STT/TTS 厂商预设下拉、assistant 播报按钮、停止播报状态和播放结束自动恢复已落地；完整设计系统仍需继续收敛。最后更新：2026-07-02。

## 1. 目标

- 移动端优先。
- 聊天主流程极简稳定。
- 支持全局字体大小调节且布局自适应。
- 支持主题换色和深浅色。
- 桌面端能力不能破坏移动端可读性。

## 2. 核心页面

1. 对话主页。
2. 历史会话。
3. 模型选择。
4. 设置。
5. 技能市场。
6. 搜索。
7. 记忆 / Dreaming 报告。
8. 数据导出。
9. 语音 / STT / TTS 配置。

## 3. 移动端原则

- 单手可操作。
- 底部输入区稳定，不被键盘遮挡。
- 长文本消息可折叠 / 跳转。
- 附件、语音、图片入口不挤占输入空间。
- 模型切换必须清晰展示当前模型和渠道。

## 4. 字体调节

- 字体大小影响全局文本比例。当前实现为 90%–120% 全局缩放，使用应用级 `TextScaler`，设置保存在本地 `SharedPreferences`。
- 缩放步进为 5%，默认 100%；移动端正文以 15sp 为基准，最大缩放后正文不超过 18sp。
- 空状态品牌标题为 26sp，最大缩放后约 31.2sp；禁止恢复到 40sp+ 的大标题。
- Markdown 正文 15sp / 行高 1.60；H1/H2/H3 分别为 22sp / 20sp / 18sp；代码块 13sp；元信息 11–12sp。
- 输入区、消息气泡、按钮、列表项同步适配。
- 最大字体下仍保持主要操作可见。设置页已有“字体大小”入口、预览和恢复默认操作。
- 不允许出现一个屏幕只显示一两个字的布局。

## 4.1 对话页 Markdown 渲染

- 对话页使用 `LatexMarkdownWidget` 渲染 assistant 与流式回复，具体实现方案见 `docs/markdown-rendering.md`。
- 标准 Markdown 使用 GitHub Web 扩展集，覆盖标题、强调、列表、链接、引用、代码块、水平线、表格、任务列表、脚注、删除线等常见格式。
- 兼容旧式 `[[img:URL]]` 图片写法，内部转换为标准 Markdown 图片。
- 支持 `$...$` 行内公式与 `$$...$$` 块级公式。
- 支持 `mermaid` 图表、`drawio` / `mxgraph` 代码块识别。
- 支持 HTML `<details>` 折叠块与旧式 `:::details` / `:::collapse`。
- HTML `<audio>` / `<video>` v1 先以安全媒体卡片展示来源，不执行内嵌脚本。

## 5. 附件入口

- 输入区保留“添加附件”入口。
- 移动端支持相机 / 相册；桌面端和移动端都支持文件选择。
- 当前已接入统一附件策略：每条消息最多 8 个附件，单个附件最大 25 MB，支持图片 / PDF / 普通文档分类。
- 附件校验失败必须用 SnackBar 给出明确原因，不能写入半残缺消息。
- 发送后的附件在消息气泡内以文件卡片展示文件名、类型图标和大小；图片展示本地缩略图；音频卡片展示本地转写状态，状态文案只包含“等待转写 / 转写完成 / 未识别到文字 / 转写失败”，不展示本机路径；音频卡片可打开详情弹窗查看 / 复制转写正文。
- 设置页“语音输入”弹窗提供 OpenAI 兼容 STT 配置：启用开关、厂商预设、Base URL、模型、API Key；厂商预设 v1 支持 OpenAI 官方、Groq STT 与自定义 OpenAI 兼容，一键填充 Base URL / 模型；API Key 输入框默认不回显明文，留空时保留已有密钥。
- 设置页“语音播报”弹窗提供 OpenAI 兼容 TTS 配置：启用开关、厂商预设、Base URL、模型、音色、API Key；厂商预设 v1 支持 OpenAI 官方与自定义 OpenAI 兼容，一键填充 Base URL / 模型 / 音色；API Key 输入框默认不回显明文，留空时保留已有密钥。
- assistant 消息操作区提供“语音播报”按钮，仅非空 assistant 文本展示；用户消息不展示播报按钮，避免误触和布局噪声。播报生成中显示禁用的“正在生成语音”状态，播放中切换为“停止播报”按钮；原生播放完成、停止或错误回传后自动恢复为“语音播报”，避免播放结束后 UI 仍显示占用状态。

## 6. 主题

- 主题色可切换。
- 硬编码颜色逐步迁移到主题色。
- 推理内容、工具调用、系统消息、错误状态使用明确视觉层级。
