# SimiChat 整体架构设计

> 状态：初版。最后更新：2026-06-27。

## 1. 架构目标

SimiChat 的架构必须同时支撑三类产品形态：

1. **移动端核心聊天工具**：单聊、多模型、流式输出、本地存储、附件、多模态、模型切换。
2. **长期陪伴与记忆系统**：本地 Markdown 原始档案、本地数据库、核心记忆点、本地检索、上下文压缩、Dreaming。
3. **生态扩展平台**：MCP、技能市场、社交通道、个人接口中转、数据同步、数字孪生。

核心约束：移动端优先、本地优先、隐私优先、可测试、可演进。

## 2. 当前代码分层

```text
lib/
├── core/                 # 领域核心与基础设施
│   ├── ai/               # 多模型协议、SSE、模型测试、模型能力
│   ├── context/          # 上下文构建、压缩、令牌估算
│   ├── crypto/           # 接口密钥加密
│   ├── database/         # drift 数据库、表、DAO
│   ├── mcp/              # MCP 客户端
│   ├── notification/     # 本地通知
│   └── skills/           # 技能与技能市场
├── features/             # 页面级功能
├── shared/               # 状态提供器与复用组件
└── l10n/                 # 国际化
```

## 3. 目标分层

### 3.1 表现层

- 移动端优先界面：聊天、历史、设置、技能、搜索、附件、语音、图片。
- 桌面端复用同一业务层，但不以桌面体验牺牲移动端主流程。

### 3.2 应用状态层

- Riverpod provider 管理页面状态和领域状态。
- 流式输出、当前会话、模型选择、系统提示词、MCP 连接状态都必须可观察、可取消、可测试。

### 3.3 领域服务层

- 多模型协议统一抽象。
- 上下文构建、记忆检索、Dreaming、智能体编排、技能注入都作为可替换领域服务。

### 3.4 本地数据层

- SQLite / drift：结构化数据与查询。
- Markdown 原始档案：每个会话的完整原始文本记录。
- 文件存储：语音、图片、导出包、临时文件。
- 安全存储：接口密钥、同步凭证、第三方授权令牌。

### 3.5 外部连接层

- 模型厂商接口。
- MCP 服务器。
- 技能市场。
- 社交平台。
- 笔记工具和云同步。

## 4. 核心数据流

### 4.1 单次聊天

```text
用户输入
  -> 附件/语音/图片预处理
  -> 写入 SQLite 消息
  -> 追加 Markdown 原始档案
  -> 读取会话设置和模型
  -> 检索 Key Points / 本地知识库
  -> ContextBuilder 构建上下文
  -> AiService 调用协议适配器
  -> SSE 流式输出
  -> 写入助手消息
  -> 触发标题生成 / 压缩 / Dreaming 候选队列
```

### 4.2 Dreaming

```text
定时任务
  -> 找到当天新增对话
  -> 汇总 Markdown 和 SQLite 消息
  -> 提取摘要、关键事实、偏好、任务、画像线索
  -> 写入 Key Points / 用户画像 / 会话摘要
  -> 生成可审阅报告
```

### 4.3 社交通道

```text
外部消息通道
  -> 频道适配器鉴权
  -> 消息归一化
  -> 映射到本地会话
  -> 进入聊天管线
  -> 回复发送回外部通道
```

## 5. 生产化门禁

每个功能 Done 前必须满足：

1. **功能验证**：单元测试 / 组件测试 / 集成测试 / 真机冒烟至少覆盖主路径。
2. **性能验证**：给出关键路径耗时或复杂度评估，避免长会话、搜索、压缩卡顿。
3. **安全验证**：检查密钥、日志、文件权限、导出授权、第三方数据发送边界。
4. **文档同步**：对应 `docs/` 实现文档更新，`AGENTS.md` 进度回写。
