# 需求规格

## 1. 对话主页

- 顶部居中：会话议题（AI 自动抽取，首条回复后异步生成，可手动修改）
- 顶部左侧：历史会话入口
- 顶部右侧：新建会话按钮
- 消息流：用户消息右对齐，AI 回复左对齐
- AI 回复支持：Markdown、代码块（语法高亮+复制）、图片、LaTeX
- 每条 AI 回复底部操作：复制、重试
- 流式输出（SSE），支持中断
- 底部输入区：
  - 多行文本框，Enter 发送，Shift+Enter 换行
  - 左侧 `+`：相机拍照 / 本地照片 / 文件上传
  - 右侧：发送按钮

## 2. 模型选择器（侧边栏）

- 位置：侧边栏顶部（历史会话列表上方）
- 展示：当前选中模型的名称 + 渠道名，点击展开下拉列表
- 列表内容：所有渠道下的全部模型，不去重穷举
  - 每项显示：`渠道名 / 模型名`（如 `OpenAI / gpt-4o`、`Claude / claude-opus-4-6`）
  - 同名模型在不同渠道下各自独立显示
- 切换后立即生效，更新当前会话的 `default_channel_model_id`
- 新建会话时自动选中上次使用的模型

## 3. 历史会话页

- 滑动列表，按 `last_message_at` 倒序
- 顶部搜索（议题 + 内容全文搜索）
- 文件夹分组展示，可展开/折叠
- 每条会话右侧 `...`：重命名、移入文件夹、删除
- 新建文件夹入口

## 4. 设置页

- 入口：右上角头像
- 模型渠道管理：
  - 新增/编辑/删除渠道
  - 字段：渠道名、Base URL、API Key、协议类型
  - 协议：`openai_chat` / `openai_response` / `claude` / `gemini`
  - 每渠道可配置多个模型，设置默认模型
- 主题：深色 / 浅色
- 压缩阈值配置（默认 2000 tokens）

## 5. 响应式布局

| 平台 | 布局 |
|------|------|
| 移动端 | 单栏，历史页独立路由 |
| 桌面端（宽 > 720px） | 左侧边栏（历史列表）+ 右侧对话区 |
