## 主页（ChatPage）

```
┌─────────────────────────────────┐
│  [历史]   议题标题（居中）  [新建] │  ← AppBar
├─────────────────────────────────┤
│                                 │
│   AI 回复（左对齐，带头像）       │
│                                 │
│              用户消息（右对齐）   │
│                                 │
│   AI 回复                       │
│   [复制] [重试]                  │
│                                 │
├─────────────────────────────────┤
│ [+]  输入框（多行自动增高）  [发送]│  ← 底部输入区
└─────────────────────────────────┘
```

### 消息气泡

- 用户：右对齐，圆角矩形背景，主题色
- AI：左对齐，无背景或浅灰背景，带模型图标
- 流式输出时末尾显示光标动画
- 代码块：深色背景，顶部显示语言名 + 复制按钮

### 附件菜单（+ 号展开）

底部弹出 BottomSheet，三个选项：
- 相机拍照
- 从相册选择
- 选择文件

## 设置页（SettingsPage）

分组列表：
1. **模型渠道** — 渠道列表，右侧 + 新增
2. **外观** — 深色/浅色主题切换
3. **上下文** — 压缩阈值滑块（500~5000 tokens）
4. **关于** — 版本号

### 渠道编辑页

表单字段：
- 渠道名称（TextFormField）
- Base URL（TextFormField，带格式校验）
- API Key（密码输入框，存储时加密）
- 协议类型（SegmentedButton）
- 模型列表（可增删，设置默认）

## 侧边栏（Drawer / 桌面侧边栏）

### 移动端

从左侧滑出 Drawer，宽度 300px。

### 桌面端

宽度 > 720px 时，左侧固定显示侧边栏（280px），右侧显示当前对话。

### 侧边栏布局

```
┌──────────────────────────────┐
│ ▼ OpenAI / gpt-4o        ▼  │  ← 模型选择器（顶部固定）
├──────────────────────────────┤
│  [搜索框]          [新建文件夹]│
├──────────────────────────────┤
│ ▼ 文件夹 A                    │
│   · 会话标题 1     2024-01-01 │  ← 历史会话列表
│   · 会话标题 2     2024-01-02 │
├──────────────────────────────┤

│ 昨天                          │
│   · 会话标题 4     昨天   [..] │

### 模型选择器

- 默认收起，显示当前选中模型：`渠道名 / 模型名`
- 点击展开下拉菜单，列出所有渠道的全部模型（不去重）
- 分组按渠道展示，每项格式：`渠道名 / 模型名`
- 选中后立即切换，更新当前会话的模型绑定
- 同名模型在不同渠道下各自独立，如：
  ```

## ChatGPT 风格界面约束

主聊天界面以 ChatGPT 的信息架构为准：

- 桌面端左侧固定侧边栏，顶部为“新聊天”和设置入口，中部为搜索和历史会话。
- 模型选择器放在聊天区顶部，以轻量 pill 形式展示当前 `渠道 / 模型`。
- 消息内容区居中，最大宽度约 860px；AI 回复使用无气泡正文块，用户消息使用右侧圆角气泡。
- 底部输入区使用居中 composer，最大宽度约 860px，支持附件、停止生成、发送和 token 计数。
- 空会话页展示欢迎语和建议卡片，而不是空白列表。
- 跨 Android / iOS / Windows / macOS / Linux 保持同一信息架构，仅通过响应式断点切换侧边栏 / Drawer。
