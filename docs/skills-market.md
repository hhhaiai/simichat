# 技能市场集成方案

> 对应模块：M7。状态：初版。最后更新：2026-06-27。

## 1. 目标

支持从多个技能市场搜索、下载、安装、启用、禁用和更新技能，并将技能安全注入聊天上下文或智能体编排中。

## 2. 当前基础

- 已接入 SkillHub.cn 搜索 / 导入。
- 支持 SHA-256 校验。
- 支持将技能 instructions 注入系统提示词。

## 3. 技能来源

- SkillHub.cn。
- OpenClaw 技能市场。
- 腾讯等第三方技能市场。
- 用户本地导入。

## 4. 技能模型

```text
Skill
- id
- name
- description
- instructions
- source
- sourceUrl
- sourceSha256
- sha256Verified
- permissions
- version
- isEnabled
```

## 5. 安全策略

- 默认只允许提示词类技能。
- 工具类技能必须声明权限。
- 安装前展示来源、校验状态、权限列表。
- 更新时保留回滚版本。
- 不执行未经隔离的任意代码。

## 6. 注入策略

- 全局启用技能进入系统提示词。
- 会话级技能优先级高于全局技能。
- 智能体可绑定固定技能集。
- 过长技能说明需要摘要或按需检索。

## 7. 测试要求

- 导入校验测试。
- SHA-256 不匹配阻止启用。
- 技能禁用后不再注入。
- 多技能提示词长度控制测试。
- 恶意技能内容不泄露密钥的安全评估。
